# islam

A modern, mobile-friendly introductory reference on Islamic principles and teachings — published as a GitHub Pages site.

## About

The site introduces the core beliefs and practices of Islam: the five pillars, the six pillars of faith, the Quran, the Prophet Muhammad ﷺ, everyday practice, and a glossary of common terms. It is built to be readable on any device.

## Content sections

- Introduction to Islam
- Five Pillars of Islam
- Six Pillars of Faith (Iman)
- The Quran
- The Prophet Muhammad ﷺ
- Daily Practice
- Glossary of common Islamic terms

## Tech

- Vanilla HTML, CSS, and a small JavaScript enhancement for the mobile menu and scroll-reveal animations
- No build step or external dependencies
- Responsive, mobile-first layout with an Arabic/Islamic colour palette
- Arabic script set in the Amiri typeface; headings set in Lalezar; body in Quicksand

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
